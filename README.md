## Projects

**PitStop** — [live demo](https://pitstop-production-f23c.up.railway.app/app)
A web app that helps Toronto rideshare drivers find the 3 nearest open washrooms from their GPS location. FastAPI backend, PostgreSQL on Railway, Docker, Leaflet.js map, 877 real locations merged from OpenStreetMap and Toronto Open Data. Built from a problem I had during ~20 months of driving rideshare.

**Toronto Road Intel**
A computer-vision pipeline that detects and maps road damage from dashcam footage. Collected real driving data, synced it with GPS, ran YOLOv8 inference, and mapped results with Folium. Python, OpenCV, SQLite.

**JobFlow** — AI job-search assistant
Parses job postings and resumes, then runs a multi-step pipeline to highlight skill gaps and suggest improvements. FastAPI, Pydantic, structured outputs.

**AI Code Review Tool**
A multi-agent system where specialized reviewers (security, performance) analyze code in parallel and produce a structured report.
